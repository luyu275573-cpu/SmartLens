# SmartLens 隐私政策（开发版本）

更新日期：2026-10-11

SmartLens 当前版本只在用户主动使用相机预览、拍照或系统相册选择器时访问图片。

## 数据处理

- 相机画面仅用于设备侧预览和后续识别链路，当前版本没有网络请求和图片上传代码。
- 相册选择使用系统图片选择器返回的授权 URI，不申请全量媒体读取权限。
- 当前版本不会把图片、识别文本或票据字段写入远程服务。
- 识别结果保存、删除、导出和历史记录功能尚未上线；对应功能上线前会补充明确的保存期限和删除方式。

## 权限

- 相机权限：用于拍照和相机预览。用户拒绝后，应用保留静态页面并停止相机能力。
- 相册访问：通过系统图片选择器按用户选择授权，不声明全量媒体读取权限。
- 当前版本不声明网络访问权限。

## 用户控制

用户可以在系统设置中随时撤回相机权限，也可以退出相册选择器。相机进入后台或页面离开时，应用会停止预览并释放相机资源。

## 联系与变更

这是开发阶段隐私说明。正式发布前需要补充运营主体、联系方式、第三方 SDK 清单、数据主体权利和生效日期，并由项目负责人完成合规审核。
