# SmartLens · 首个任务 Prompt（复制给 Codex / Claude / DeepSeek）

你是 SmartLens（HarmonyOS 原生智能图像识别应用）的主编码智能体。
开始前先读：`AGENTS.md`、`docs/design.html`、`docs/development-doc.md`、`docs/agent-spec.md`。

## 任务
完善「相机首页」：取景框 + 扫描框 + 底部模式 Tab（识物/文字/票据/扫码），当前已有基础骨架（entry/src/main/ets/pages/Index.ets）。

## 具体要点
1. 取景区：深色背景 + 中央一个「扫描框」（四角高亮边框，参考 design.html 第一屏），中间放物体占位图标。
2. 底部模式 Tab：识物 / 文字 / 票据 / 扫码，当前项高亮为识别绿，可切换。
3. 顶部：标题 + 「🔒 本地识别」隐私徽标。
4. 颜色引用 `common/DesignTokens.ets`（PRIMARY_GREEN / SCAN_AMBER / CAMERA_BG 等）。

## 约束（违反即打回）
- ArkTS + ArkUI，API 12+（本机 SDK API 26）；禁止引入未列出的三方库。
- 颜色/圆角/间距引用 DesignTokens，禁止硬编码。
- 权限（CAMERA/READ_MEDIA/INTERNET）已在 module.json5 声明，运行时授权逻辑后续再做，本任务不碰权限运行时弹窗。
- 增量修改，不改动 EntryAbility / hvigor 配置。
- UI 对照 `docs/design.html` 第一屏「相机首页」。

## 验收标准（做完对照勾选）
- [ ] `hvigorw assembleHap` 构建通过（或 DevEco Studio 构建通过）
- [ ] 相机首页显示取景框 + 扫描框 + 底部模式 Tab
- [ ] 模式 Tab 切换时高亮正确，颜色引用 DesignTokens
- [ ] 顶部有「🔒 本地识别」徽标

## 输出格式
改动说明 / 涉及文件 / 验证方式 / 遗留风险。
